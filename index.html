05 · FAQ

Frequently asked

Who is Rudratosh Shastri?

Rudratosh Shastri is an AI-agent security and full-stack engineer based in Indore, India, with about 15 years in backend engineering. He is Technical Lead and Senior Backend Architect at PharmaForceIQ, created the open-source projects buried-injections and taintgate, and founded Export Bank Statement and Brisk Type.

What is buried-injections?

buried-injections is an open-source, MIT-licensed benchmark that tests ten prompt-injection detectors against 629 real attacks from AgentDojo, with calibrated reporting. New detectors can be added in one line.

What is taintgate?

taintgate is an open-source, MIT-licensed policy gate for AI-agent tool calls. It tracks where each argument came from and blocks actions built from untrusted input, instead of relying only on detecting suspicious-looking text.

How do you protect an AI agent from prompt injection?

Use two layers. First, benchmark your prompt-injection detector against real attacks, since detection alone tops out. Second, add a provenance-aware gate that refuses tool calls whose arguments were derived from untrusted content such as emails, web pages, or reviews.

What is Export Bank Statement?

Export Bank Statement is a web app that converts PDF bank statements into accountant-ready formats including Excel, CSV, QBO, OFX and QIF.
